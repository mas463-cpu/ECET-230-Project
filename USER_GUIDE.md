# Air Mouse User Guide

## Overview
The Air Mouse is a handheld motion-controlled mouse using an MPU6050 gyroscope and Arduino-Leonardo microcontroller.

## Power
Connect through USB-Micro.

## Operation
Tilt device to move cursor.
Press left button for left click.
Press right button for right click.

## LEDs
1 LED for power indication, Static green LED for ON
2 LEDs are for status, green for recalibration and yellow for in use
3 Total LEDs

## Troubleshooting
- ONLY for BREADBOARD
If movement drifts:
- Reconnect USB
- Reset board
- Recalibrate MPU6050
