# Air Mouse User Guide

## Overview
The Air Mouse is a handheld motion-controlled mouse using an MPU6050 gyroscope and ATmega32U4 microcontroller.

## Power
Connect through USB-Micro.

## Operation
Tilt device to move cursor.
Press left button for left click.
Press right button for right click.

## LEDs
The device includes three LEDs:
- One power LED connected to the 3.3V rail
- One green status LED for MPU6050 detection
- One yellow LED used during calibration and operation
  
## Troubleshooting
If movement drifts:
- Reconnect USB
- Reset board
- Recalibrate MPU6050
