## Hardware Used

- **Arduino Leonardo**  
  Main microcontroller with built-in USB HID support.

- **MPU6050 Gyroscope/Accelerometer Module**  
  Measures orientation and angular motion for detecting pointing direction.

- **Push Buttons**  
  Used for mouse click, scroll, and reset functions.

- **LED Indicator**  
  Provides visual feedback such as power or reset status.
