# PCB Design

This folder contains the KiCad PCB design files for the ECET-230 Air Mouse Project.

## Features
- ATmega32U4 microcontroller
- MPU6050 motion sensor
- USB Micro interface
- Multi-layer PCB routing
- Ground plane implementation
- Push button inputs
- LED indicators

## Design Notes
The PCB was routed using KiCad with multi-layer routing and vias to reduce trace crossing. A ground plane was added to improve grounding and simplify routing.
